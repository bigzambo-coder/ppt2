# PPT 자동화 프로그램 (ppt2)

주제와 대상 기관을 입력하면 제안서·발표PPT·회사(강사)소개서를 자동으로 만들어 .pptx로 내려받는 프로그램. 현재 Phase 1(MVP) 상태.

## 로컬에서 실행하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` → "새 문서 만들기"로 이동해서 바로 써볼 수 있어요. API 키가 없어도 기본 템플릿 콘텐츠로 정상 동작해요.

## API 키 설정 (선택, 있으면 결과물 품질이 좋아져요)

`.env.example`을 복사해서 `.env.local`을 만들고 채워 넣으세요.

```bash
cp .env.example .env.local
```

| 변수 | 용도 | 없으면? |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude가 슬라이드 내용을 직접 작성 | 결정론적 기본 템플릿 문구로 대체 |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 대상 기관 실제 정보 웹검색 (무료: [네이버 개발자센터](https://developers.naver.com)) | 리서치 단계 조용히 생략 |
| `ACCESS_CODE` | 배포 후 접근 코드 게이트(HTTP Basic Auth) | 게이트 없이 누구나 접속 가능 (로컬 개발 땐 비워두면 됨) |

## 현재 만들어진 것 (Phase 1)

- **기관 유형 분류기**(`lib/classifier.ts`) — 공공기관 일반/입찰, 기업, 소상공인, 학교, 행사 6가지 유형을 키워드로 자동 판별
- **디자인 엔진**(`lib/design/`) — 기관 유형·업종·대상에 맞는 10가지 컬러/타이포 프리셋 중 자동 선택
- **리서치 엔진**(`lib/research.ts`) — 네이버 검색 API 연동 준비 완료 (키 넣으면 바로 동작)
- **콘텐츠 생성기**(`lib/content/`) — Claude API로 슬라이드 내용 작성, 키 없으면 기본 템플릿으로 폴백
- **PPTX 빌더**(`lib/pptx/`) — 표지·구분·목록·비교·단계·통계·표·인용·마무리 9종 레이아웃, 자동 QA 검증(레이아웃 다양성, 3연속 금지)
- **웹 UI** — 새 문서 만들기(`/new`), 지난 프로젝트(`/projects`)
- **접근 코드 게이트**(`proxy.ts`) — 배포 후 API 비용 남용 방지
