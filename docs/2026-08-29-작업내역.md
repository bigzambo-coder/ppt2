## 1. 진짜 원인이었던 것

### 증상

화면에 **"AI 키 없음"이라고 표시되는데 슬라이드는 40장** 생성되는 모순이 있었다.
키가 없으면 12장(섹션당 1장)만 나와야 하므로, 이 조합은 논리적으로 불가능하다.

### 원인

`lib/anthropic.ts`의 `max_tokens: 4096`.

- 슬라이드 한 장을 작성하는 데 약 300~500 출력 토큰이 든다.
- 따라서 **15장이 넘어가면 응답이 중간에 잘린다.**
- 잘린 응답도 형식상으로는 `tool_use` 블록을 포함하므로 유효해 보이지만, 내부 JSON이 깨져 파싱에 실패한다.
- 코드는 이때 조용히 `null`을 반환하고 기본 뼈대(빈 껍데기)로 넘어간 뒤, UI에 **"기본 구성(AI 키 없음)"이라고 거짓 표시**했다.

이 때문에 키를 정상적으로 넣어도 소용없어 보였고, 존재하지 않는 환경변수 문제를 찾아 헤매게 됐다.
20장은 아슬아슬하게 한도 안에 들어와 통과했고, 40장에서 터진 이유가 이것이다.

### 수정

| 항목 | 변경 내용 |
|---|---|
| 청크 생성 | 슬라이드를 **8장씩 나눠 병렬 호출**. 각 묶음은 전체 목차를 참고하되 자기 구간만 작성하고, `PlannedSlide.index` 기준으로 병합 |
| 토큰 한도 | `max_tokens` 4096 → **16000** |
| 잘림 감지 | `stop_reason === "max_tokens"` 명시적으로 확인 |
| 실패 전달 | `LlmResult.error` → `ContentResult.llmError` → `GeneratedDeck.llmError` → 편집 화면까지 전달 |

이제 AI 호출 실패가 "키 없음"으로 위장되지 않는다.

### 결과

**40장 / 24초 / QA 오류 0건 / 제목 전부 실제 문장.**

### 교훈

LLM 경로에서 조용한 `return null`은 결국 "기능 미설정"과 구별할 수 없게 된다.
**실패에는 항상 사유를 함께 실어 보내야 한다.**

## 2. 디자인 — 설치된 스킬을 실제로 사용

`anthropic-skills:lecture-slide-creator-v3` (SimpleP 디자인 분석)을 불러와 구체적 규칙을 적용했다.

### 적용한 것

- **우상단 페이지 번호** — 아예 없었다. 없으면 이유는 몰라도 "미완성" 느낌이 난다.
- **좌우 여백 0.6" → 0.8"** (SimpleP 그리드 기준)
- **표지 재설계** — 의미 없이 떠 있던 라임색 원을 삭제하고, 컬러 패널 + 연한 연도 + 액센트 룰의 에디토리얼 구성으로 교체
- **마무리 슬라이드** — 가운데 작은 글씨 → 좌측 정렬 대형 + 룰
- **모노크롬 팔레트 2종 추가** (`SimpleP Monochrome`, `SimpleP Ink`) — 제안서·IR·회사소개서·보고서 유형에 자동 매칭

### 렌더링해서 추가로 잡은 결함 2건

실제 PPTX를 이미지로 뽑아 눈으로 확인한 뒤에야 보인 문제들이다.

1. **카드가 내용과 무관하게 슬라이드 끝까지 늘어나** 각 박스의 4분의 3이 비어 있었다
   → 예상 줄 수 기준으로 높이를 계산하고, 정중앙이 아닌 위쪽 25% 지점에 배치(정중앙은 제목과의 간격을 벌렸다)
2. **표지 키워드가 제목의 첫 단어를 그대로 반복**해 정보를 더하지 않았다
   → 연도로 교체

스크롤을 없애고 한 화면에서 넘기는 방식으로 교체했다.

- `‹` `›` 버튼
- 슬라이드 선택 드롭다운
- 번호 점 스트립(전체 슬라이드로 바로 이동)

검증 결과 `scrollHeight === innerHeight` — **스크롤이 아예 발생하지 않는다.**
기존의 긴 썸네일 레일은 40~60장에서는 사용할 수 없는 구조였다.

## 검증 방법 메모

디자인 작업은 **반드시 실제 PPTX를 이미지로 뽑아 눈으로 확인**해야 한다.
빌드 통과·타입 체크·API 레벨 QA를 모두 통과하고도 화면에서는 엉망인 경우가 실제로 있었다.

PowerPoint COM으로 슬라이드를 PNG로 내보내는 방법:

```powershell
$app = New-Object -ComObject PowerPoint.Application
$pres = $app.Presentations.Open($pptxPath, $true, $false, $false)
$pres.SaveCopyAs($outDir + "\d", 18)   # 18 = ppSaveAsPNG, 슬라이드당 PNG 1장
$pres.Close(); $app.Quit()
```
